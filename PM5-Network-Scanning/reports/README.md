# PM5 – Network Scanning

## Objective
To perform network host discovery using Nmap.

## Tool
- Nmap

## Scan Type
Ping Scan / Host Discovery (-sn)

## Summary
- 256 addresses were scanned in the lab network.
- 4 hosts responded.

## Data Protection
Private IP addresses, MAC addresses, gateway details and raw scan
files have been excluded from this public repository.
